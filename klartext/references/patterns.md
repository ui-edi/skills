# Klartext pattern library

Use these patterns as evidence, not as a find-and-replace list. A phrase can be completely natural in the right context. Remove it when it delays the point, inflates a plain fact or replaces substance with performance.

Contents: [Top 12](#top-12-the-loudest-giveaways) · [Deutsch](#deutsch) · [English](#english) · [Text types](#text-types)

## Top 12: the loudest giveaways

Language-independent. Check these first.

1. **Staged contrast.** "It's not X, it's Y." / «Es geht nicht um X, sondern um Y.» Say the real claim. Keep a contrast only when it corrects a belief the reader really holds.
2. **Announcing instead of saying.** "Here's the thing." / «Und jetzt kommt's.» Delete the announcement, say the thing.
3. **Fragment stacks.** "No code. No setup. Just results." / «Kein Stress. Kein Aufwand. Einfach Ergebnisse.» Write one complete sentence.
4. **Self-answered questions.** "The result? Huge." / «Das Ergebnis? Beeindruckend.» Make it a statement. Real questions to the reader are fine.
5. **Colon reveals.** "The secret: consistency." / «Das Geheimnis: Konstanz.» Normal sentence. Colons stay for lists and labels.
6. **"Nobody tells you this."** / «Was dir keiner sagt.» Drop the fake secrecy, keep the insight.
7. **Importance labels.** "This is crucial." / «Das ist entscheidend.» Show what changes, for whom.
8. **Reaction instructions.** "Let that sink in." / «Lies das nochmal.» Let the fact stand.
9. **Decorative triads.** "Faster, smarter, better." / «Schneller, smarter, besser.» Keep three only if there are three real things.
10. **Generic scene-setting.** "In today's fast-paced world" / «In der heutigen schnelllebigen Welt». Start with the subject.
11. **Fake-profound endings and recaps.** A closing aphorism or a summary of what was just said. End on the last useful point or next step.
12. **Dash as default glue.** Several — dashes — per paragraph. Use real punctuation.

## Deutsch

### Floskel-Einstiege

Streichen, wenn sie den Punkt nur verzögern:

- «In der heutigen (digitalen / schnelllebigen) Welt …»
- «Hast du dich schon mal gefragt, …?»
- «Stell dir vor, …»
- «Lass uns eintauchen.» / «Tauchen wir ein.»
- «In diesem Artikel / Beitrag erfährst du …»
- «Es ist kein Geheimnis, dass …»
- «Seien wir ehrlich: …» / «Mal ehrlich?»

### Ankündigungen und Spannungsbögen

- «Und jetzt kommt der Clou / das Beste / der Knackpunkt.»
- «Hier wird es spannend.»
- «Das Spannende daran?»
- «Lass mich das kurz erklären.»
- «Und genau das ist der Punkt.»
- «Ich will hier ganz konkret werden, denn …»

### Inszenierte Gegensätze und Negativ-Listen

- «Es geht nicht darum, X. Es geht darum, Y.»
- «Das ist kein X. Das ist ein Y.»
- «Nicht X, nicht Y, sondern Z.»
- «Kein Abo. Keine Werbung. Einfach Training.»

Als ganzen Satz schreiben: «ROUND hat kein Abo und keine Werbung.»

### Wichtigkeits-Etiketten und Schein-Analyse

- «Das ist entscheidend / essenziell / von zentraler Bedeutung.»
- «… was die Bedeutung von X unterstreicht.»
- «… und zeigt eindrucksvoll, wie …»
- «Das macht den Unterschied.»
- «Ein echter Meilenstein.»

Ersetzen durch die konkrete Folge oder streichen.

### Aufgeblasene Wörter

Standardmässig meiden, ausser sie bezeichnen etwas Präzises:

- nahtlos, ganzheitlich, massgeschneidert, innovativ, revolutionär, bahnbrechend
- Mehrwert, Synergien, Potenzial entfalten / freisetzen, auf das nächste Level heben
- Gamechanger, Booster, smart (als Füllwort), next level
- vielfältig, facettenreich, essenziell, unverzichtbar
- optimieren (ohne Angabe, was und wie), Lösung (für jedes Produkt)
- «Reise» für jeden Prozess («deine Fitness-Reise»)

### Nominalstil

KI-Deutsch stapelt Substantive. Zurück zu Verben:

- «die Durchführung der Analyse» → «analysieren»
- «zur Verbesserung der Benutzerfreundlichkeit» → «damit die App leichter zu bedienen ist»
- «eine Entscheidung treffen» → «entscheiden»
- «in der Lage sein, zu» → «können»

### Leere Füllwörter

Streichen, wenn sie nichts tragen: einfach, wirklich, tatsächlich, eigentlich, letztendlich, grundsätzlich, absolut, definitiv, quasi, sozusagen, im Grunde, nicht zuletzt.

Behalten, wenn sie zur gesprochenen Stimme des Schreibers gehören oder echte Betonung tragen.

### Chat-Reste

Typisch für KI-Antworten, die in Texte kopiert wurden:

- «Gerne!», «Absolut!», «Klar doch!» am Anfang
- «Ich hoffe, das hilft!», «Viel Erfolg!» am Ende
- «Hier ist eine überarbeitete Version deines Textes:»
- «Natürlich kann ich dir dabei helfen.»

### Englisch im Deutschen

Anglizismen sind okay, wenn der Schreiber sie wirklich so benutzt (Training, App, Update). Aufgeblasene sind es nicht: «leveragen», «Insights generieren», «einen Impact haben», «das ist ein Must-have». Wörtliche Übersetzungen fallen auf: «Das macht Sinn» ist inzwischen verbreitet und darf bleiben; «am Ende des Tages» meist nicht.

### Schluss-Floskeln

- «Fazit: …» über drei Sätzen Text
- «Zusammenfassend lässt sich sagen …»
- «Am Ende zählt nur eins: …»
- «Die Zukunft ist jetzt.»

### Schweiz

- «ss» statt «ß», wenn der Schreiber Schweizer ist.
- Anführungszeichen «…» beibehalten.
- Helvetismen (parkieren, Velo, grillieren, Znüni) sind Stimme, keine Fehler.

## English

### Stock openers

- "In today's fast-paced (digital) world …"
- "Have you ever wondered …?" / "Imagine …" / "Picture this …"
- "Let's dive in." / "Let's unpack this."
- "In this article, we'll explore …"
- "Honestly?" / "Let's be real." before an ordinary claim

### Tee-ups and reveals

- "Here's the kicker." / "Here's where it gets interesting."
- "And that's when it clicked."
- "Let me be clear." / "Here's what I mean."
- "The uncomfortable truth is …"
- "I want to be specific here, because this is where people get stuck."

### Staged contrasts and negative stacks

- "It's not just X, it's Y." / "This isn't X. It's Y."
- "You don't have an X problem. You have a Y problem."
- "Not a tool. Not a feature. A revolution."
- "No X. No Y. Just Z."

### Importance labels and shallow analysis

- "This matters." / "This changes everything." / "a pivotal moment"
- "plays a vital role", "stands as a testament", "solidifies its position"
- trailing "…, highlighting / underscoring / showcasing …"

### Inflated vocabulary

delve, tapestry, realm, beacon, landscape (figurative), ever-evolving, game-changer, paradigm shift, revolutionary, unlock, supercharge, elevate, empower, harness, leverage, utilize, facilitate, foster, streamline, robust, seamless, cutting-edge, transformative, multifaceted, meticulous, intricate, paramount, "move the needle".

Keep a word when it names something precise ("robust statistics", "API landscape" in a real overview).

### Empty adverbs

just, literally, honestly, simply, actually, truly, fundamentally, crucially, importantly, inherently, quietly.

### Weak-strong verbs

"serves as" → "is"; "has the ability to" → "can"; "made a decision" → "decided"; "in order to" → "to".

### Vague authority

"Experts agree." / "Studies show." / "Many believe." Name the source and finding, or drop the claim.

### Chatbot residue

"Certainly!", "Great question!", "I hope this helps!", "Here's a revised version of your text:", "Feel free to reach out."

### Endings

"In conclusion", "Ultimately", "Overall", a recap paragraph, a mic-drop aphorism.

## Text types

What is normal in one format is slop in another. Adjust before cutting.

| Text type | Keep | Watch for |
| --- | --- | --- |
| Store listing (Play Store, App Store, itch.io) | Short feature list, clear benefits, real numbers | Buzzword stacks, "revolutionary", fake urgency, invented ratings |
| README | Headings for navigation, install steps, code blocks | Marketing tone, emoji on every heading, "seamless" |
| Job application / CV | Concrete results, numbers, tools used | «hochmotiviert», «teamfähig», «passionate» without proof, «Mit grossem Interesse habe ich …» |
| Social post / music release | Personality, emojis the writer really uses, hooks | "Nobody talks about this", fragment stacks, engagement bait |
| Email / message | Greeting and sign-off the writer normally uses | «Ich hoffe, diese Nachricht erreicht dich gut», recap of the email at the end |
| Game / app texts in the UI | Short labels, consistent terms | Synonym cycling (one button called three things) |
